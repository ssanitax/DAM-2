# Concepto de CRM

**CRM** = *Customer Relationship Management*  
Gestión de la relación con el cliente.

Software orientado a ventas / atención al cliente.

## Otros sistemas de gestión (verticales)

| Sigla | Significado |
|-------|-------------|
| SIS | *Student Information System* |
| LMS | *Learning Management System* |
| GMAO | Mantenimiento asistido por ordenador |
| PMS | Hoteles (*Property Management System*) |
| CMS | *Content Management System* |
