# Cliente y servidor

## Cliente

- Interfaz web
- HTML, CSS, JS
- Navegador web
- Compatible con Windows, Mac y Linux

## Servidor

- Stack **LAMP:** Linux, Apache, MySQL, PHP/Perl
- Variantes: PHP o Node.js + Linux + MySQL

## Prototipo (abstrayendo capas)

| Capa | Tecnología |
|------|------------|
| Cliente (C) | HTML, CSS, JS |
| Servidor (S) | PHP + SQLite |
