# Concepto de ERP

**ERP** = *Enterprise Resource Planning*  
Sistema de planificación / gestión de los recursos de una empresa.

Aborda todo el proceso de gestión de datos de la empresa.

## Áreas típicas

- Inventario
  - FK id producto
  - unidades
  - localización
- Usuarios
  - nombre
  - apellidos
  - nombre de usuario
  - contraseña
  - permisos
- Multisede
- Empleados
- Almacenes
- Facturas
- Logística
- Productos
- Incidencias
