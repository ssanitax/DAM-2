# Verificación de la instalación y configuración

Comprobar que el sistema operativo, el servidor web/runtime y el gestor de datos están bien configurados antes de dar el entorno por funcional.

## Checklist breve

- SO servidor (Linux) operativo y con hora correcta
- Servidor web y PHP/Node responden
- Conexión a la BD (SQLite / MySQL) OK
- Charset UTF-8
- Prueba mínima de la aplicación (login / CRUD simple)
