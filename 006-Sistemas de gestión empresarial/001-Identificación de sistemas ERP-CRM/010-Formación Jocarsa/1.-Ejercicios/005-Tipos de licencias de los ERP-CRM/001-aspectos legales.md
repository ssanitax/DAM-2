# Tipos de licencias de los ERP-CRM

## Tipos disponibles

- GPL
- Propietaria
- Apache

## Licencia propietaria

Se utiliza cuando te quedas el código y la propiedad, y al cliente le das únicamente:

1. Una copia de los binarios, o
2. Acceso al servicio mediante suscripción.

## Modelo tipo Odoo

- Licencia más libre (community).
- Cualquier persona se puede descargar el código fuente.
- La propiedad/marca la retiene Odoo.
- Te lo puedes instalar y personalizar (según términos).
