# Documentación de las operaciones realizadas

Registrar qué se ha hecho y qué incidencias han surgido.

## Operaciones

Fecha, entorno, pasos, resultado esperado, resultado obtenido, evidencias.

## Incidencias

Fecha, severidad, síntoma, componente (SO / web / BD / app), causa, solución, estado, prevención.

## Ejemplos típicos de laboratorio

- Fallo de conexión a la BD → revisar servicio y credenciales
- Página en blanco → revisar logs de PHP
- Caracteres rotos → forzar UTF-8
- Permisos en carpetas → ajustar owner/grupo
